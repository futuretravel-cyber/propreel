## 💳 Credit Calculation

### Image Rendering
```
Cost per image = 2 credits
```

### Examples
- Edit 1 photo: 2 credits
- Edit 5 photos: 10 credits
- Stage 1 room: 2 credits
- Remove furniture from 3 photos: 6 credits
- Convert to twilight: 2 credits

### Combined with Video
```
Total = Video Credits + (Image Credits × Number of Images)
```

**Example:**
- Social 30s video: 30 credits
- Edit 5 photos before video: 5 × 2 = 10 credits
- AI Talking Profile: 8 credits
- **Total: 30 + 10 + 8 = 48 credits**

#### `edit_image()`
```python

    preset_id: str,
    custom_prompt: str | None = None,

    guidance_scale: float | None = None

```

**Parameters:**
- `image_url`: Source image URL

## 💡 Usage Tips

### Best Practices
1. **Start with preset defaults** - They're optimized for each edit type
2. **Adjust strength carefully** - Too high can cause artifacts
3. **Use appropriate guidance** - Higher for complex edits
4. **Test on sample images** - Before batch processing
5. **Monitor credit usage** - 2 credits per render adds up

### Strength Guidelines
- **0.20-0.30:** Subtle enhancements (lighting, color)
- **0.30-0.40:** Moderate changes (sky, lawn, pool)
- **0.40-0.50:** Significant edits (staging, twilight)
- **0.50-0.60:** Major transformations (removal, complete restyle)
